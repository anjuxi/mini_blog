## 工欲善其事，必先利其器

选择趁手的工具是提升效率的第一步。好的编辑器、终端、笔记工具能让你事半功倍。

> 我常用的组合：VS Code + iTerm2 + Notion

## 自动化一切

凡是重复三次以上的操作，都应该考虑自动化。脚本、别名、快捷键都是你的朋友：

```bash
# 用别名替代长命令
alias gs="git status"
alias gc="git commit -m"
```

## 番茄工作法

25 分钟专注 + 5 分钟休息，一个简单但有效的时间管理方法。关键是：**专注时屏蔽一切干扰**。

## 批量处理

把相似的任务集中处理，减少上下文切换的成本。比如：

- 上午集中写代码
- 下午统一回复消息和邮件
- 晚上做计划和复盘

## 持续学习

技术更新很快，保持学习习惯很重要。但要注意：**学是为了用，不要为学而学**。

1. 遇到问题时再深入学习
2. 学完立即实践
3. 用输出倒逼输入（写博客就是好方法）

## 写在最后

效率不是一蹴而就的，需要不断试错和调整。找到适合自己的节奏，比盲目追求所谓的"最佳实践"更重要。
